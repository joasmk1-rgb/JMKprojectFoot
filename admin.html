Supprimer ce tournoi

Supprime définitivement le tournoi, ses inscriptions et ses matchs. Les équipes elles-mêmes (et leurs comptes) ne sont pas touchées, elles restent dans le hub.

Vérifier les doublons (noms proches)

Compare tous les noms d'équipes et de joueurs du hub (toutes équipes confondues, pas juste celles inscrites à ce tournoi) pour repérer une même personne/équipe écrite différemment — ex : "Anas", "Anas K", "Anas Kada". Rien n'est fusionné automatiquement, c'est à toi de corriger ensuite (bouton "Retirer" dans la composition d'une équipe).

Importer un tournoi déjà joué

Pour reprendre un tournoi préparé ailleurs (Excel/Word/PDF converti en CSV) plutôt que de tout ressaisir : dépose un ou plusieurs fichiers CSV d'un coup, peu importe l'ordre — le type de chaque fichier est détecté automatiquement à partir de ses colonnes. Équipes : colonnes nom, groupe. Membres : colonnes equipe, nom. Matchs : colonnes groupe, equipeA, equipeB, date, heureDebut, heureFin, terrain (terrain optionnel). Un fichier dont les colonnes ne correspondent à rien de connu est simplement ignoré (signalé dans le résultat). Les équipes déjà existantes dans le hub (même nom) sont réutilisées ; les nouvelles sont créées avec un mot de passe capitaine temporaire à leur communiquer. Les matchs en double (mêmes équipes + même date/heure) sont détectés et te sont signalés avant import.

Plusieurs anciens tournois d'un coup : ajoute une colonne tournoi (nom exact du tournoi, comme il apparaît sur ton document source) dans equipes.csv, membres.csv et matchs.csv. Chaque nom différent va automatiquement dans SON tournoi à lui : s'il n'existe pas encore, il est créé tout seul, marqué comme historique. Sans cette colonne, tout part dans le tournoi actuellement sélectionné en haut de page (comportement d'avant). Les membres importés sont rattachés à CE tournoi précis (pas à l'équipe en général) : une même équipe qui revient dans plusieurs tournois a donc un effectif bien distinct à chaque fois, jamais mélangé. Les groupes sont aussi automatiquement convertis en lettres (A, B, C...) même si ton fichier utilise des chiffres.

Encoder un résultat

Sélectionne un match pour encoder le score. Le classement se recalcule automatiquement.

Créer un championnat

Un championnat cumule les résultats de plusieurs tournois dans un seul classement (façon classement de saison). Choisis toi-même quels tournois en font partie.

Tournois inclus

Aucun tournoi créé pour l'instant.

Générer la phase finale

Prend automatiquement tous les premiers de groupe, puis complète avec les meilleurs 2èmes/3èmes (selon le nombre de qualifiés défini à la création du tournoi, jusqu'à 16) pour générer le tableau à élimination directe — classement fair-play (cartons) inclus dans les critères. Si l'effectif qualifié ne tombe pas sur une puissance de 2, les mieux classé(e)s reçoivent un "bye" (qualifié d'office, pas de match) au premier tour.

Tour suivant

Une fois tous les matchs du tour affiché ci-dessous joués (score encodé dans l'onglet Calendrier), génère le tour suivant (demi-finale, finale...) à partir des vainqueurs. Annonce le/la champion(ne) une fois la finale jouée.

Disponibilités

Tout ce qui concerne les créneaux de disponibilité se passe ici, que ce soit pour les équipes ou pour les terrains.

Disponibilités des équipes

Vue combinée : plus une case est verte foncé, plus d'équipes sont dispo à ce créneau ; un liseré rouge signale qu'au moins une équipe s'est mise "pas dispo". Prochaine étape : une couche arbitres se superposera ici avec sa propre couleur.

Sonder les équipes (façon Doodle)

Sélectionne les créneaux sur lesquels tu veux particulièrement une réponse (ex : proposition de match en dernière minute). Ils s'affichent en orange sur le calendrier de toutes les équipes tant qu'elles n'ont pas répondu dispo/pas dispo dessus.

Disponibilités des terrains

Clique ou clique-glisse sur la grille pour marquer les créneaux où le terrain sélectionné est utilisable. Comme pour les équipes, un panneau de marquage rapide permet de cocher par exemple "tous les mardis de 18h à 20h" d'un coup.
